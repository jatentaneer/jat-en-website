# J.A. Tech Entaneer Website

เว็บไซต์ตัวอย่างสำหรับ J.A. Tech Entaneer Co., Ltd.

## ไฟล์สำคัญ

- `index.html` หน้าเว็บไซต์
- `styles.css` รูปแบบ สี และการจัดวาง
- `script.js` เมนูมือถือและแบบฟอร์มตัวอย่าง
- `vercel.json` การตั้งค่าสำหรับ Vercel

## วิธีอัปโหลดขึ้น GitHub แบบง่าย

1. เข้า Repository `jat-en-website`
2. กด **Add file**
3. กด **Upload files**
4. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ลงไป
5. กด **Commit changes**

> สำคัญ: ให้อัปโหลดไฟล์ `index.html`, `styles.css`, `script.js` ไว้ที่หน้าหลักของ Repository ไม่ควรซ้อนอยู่ในโฟลเดอร์อีกชั้น

## วิธีเปิดเว็บด้วย Vercel

1. สมัครหรือเข้าสู่ระบบ Vercel ด้วยบัญชี GitHub
2. เลือก **Add New > Project**
3. Import Repository `jat-en-website`
4. Framework Preset เลือก **Other**
5. กด **Deploy**

## ก่อนใช้งานจริงควรแก้ไข

- อีเมลและข้อมูลติดต่อ
- ที่อยู่บริษัทและเบอร์โทรศัพท์
- รูปสินค้าและโลโก้จริง
- เชื่อมแบบฟอร์มกับ Formspree, Google Forms หรือระบบอีเมล
- ตรวจคำแปลภาษาอังกฤษ
